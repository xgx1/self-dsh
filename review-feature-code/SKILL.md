# Review Feature Code

双轴代码审查：Standards（编码规范）+ Spec（需求匹配）。

## 流程

加载 `code-review` — 对变更进行双轴审查：
- **Standards**: 代码是否遵循项目编码规范
- **Spec**: 代码是否匹配原始需求/PRD

## 出口
审查完成，问题已修复或已记录。
