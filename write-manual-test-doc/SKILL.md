# Write / Update Manual Test Doc

给开发者/QA 写人工测试文档；bug 修复后同步更新。两种场景共用 `dev-docs` 排版规范。

## Step 1: 加载文档规范
加载 `dev-docs`（Docs/ 排版与结构规范）。

## 场景 A：新建测试文档
内容必须包含：
- **测试功能清单** — 有哪些功能需要人工测试
- **测试流程** — 每个功能的操作步骤（按顺序）
- **预期结果** — 每一步应该看到什么
- **注意事项** — 前置条件、环境要求、已知限制

## 场景 B：bug 修复后更新
文档更新内容必须包含：
- **修复清单** — 修复了哪些问题
- **重新测试清单** — 需要重新测试哪些功能
- **变更的测试流程** — 哪些测试步骤发生了变化
- **新的预期结果** — 修复后的正确行为

## 出口
人工测试文档已生成/更新，开发者可按最新文档执行测试。
