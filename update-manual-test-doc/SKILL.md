# Update Manual Test Doc

更新人工测试文档，反映问题修复后的测试变更。

## 流程

### Step 1: 加载文档规范
加载 `dev-docs`（Docs/ 排版与结构规范）。

### Step 2: 更新测试文档
文档更新内容必须包含：
- **修复清单** — 修复了哪些问题
- **重新测试清单** — 需要重新测试哪些功能
- **变更的测试流程** — 哪些测试步骤发生了变化
- **新的预期结果** — 修复后的正确行为

## 出口
人工测试文档已更新，开发者可按最新文档重新测试。
