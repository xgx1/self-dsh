# compile-feature —— 编译 Unreal 项目，零错误零警告

> 改完代码后跑 `unrealcli dev complic`，把编译错误**和警告**全部修掉才算交付。

## 什么时候用

- 代码改动完成，需要验证能编过（触发词：编译 / 构建 / build）。
- 作为 `add-software-feature` 工作流的阶段 6 被调用。

## 怎么用

只有「编译 → 修复」两步循环：

```bash
# Step 1: 编译
unrealcli dev complic
```

Step 2：**有编译错误或警告 → 全部修复 → 重新编译。** 循环直到零错误零警告。

出口：编译通过，零错误零警告。

## 前置条件

- 本机装有 `unrealcli`（该命令负责编译 Unreal 项目）。
- 在目标 Unreal 项目的工作区下执行。

## 注意事项 / 已知坑

- 零错误**零警告**是硬门槛——警告同样算未通过，必须一并修掉。
- 修完必须重新编译验证，不要凭「看起来改对了」就宣布通过。
- 本技能的 SKILL.md 只有 19 行，仅规定「编译 → 修复」这一个循环，**没有更多参数与排错细节**；具体编译报错排查可参考 `ue-cpp-build`、`unreal-cmd` 等技能。详细步骤见 SKILL.md。
