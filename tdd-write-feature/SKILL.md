# TDD Write / Test Feature

红-绿-重构循环驱动代码编写；改完后跑全部测试、清理过时用例。

## 模式 A：TDD 编写

### Step 1: TDD 循环
加载 `test-driven-development` — 红（写失败测试）→ 绿（最小实现）→ 重构。

## 模式 B：跑测试验证

### Step 1: 运行测试
加载 `test-driven-development` — 执行全部测试套件。

### Step 2: 确认通过
所有测试必须通过。有失败 → 修复 → 重新运行。

## 收尾：清理过时测试（两种模式都做）
扫描测试文件，**删除过时的测试用例**：
- 测试已删除的功能
- 测试已重构掉的代码路径
- 与其他测试重复且无增量价值的用例

## 出口
新代码由测试驱动完成；全部测试通过；测试套件干净无冗余。
