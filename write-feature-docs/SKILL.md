# Write Feature Docs

将功能细节编写为结构化的 Obsidian 格式文档。

## 流程

### Step 1: 加载文档规范
加载 `dev-docs` — 获取 Docs/ 排版与结构规范：
- 序号禁止规范（标题、目录、列表）
- Wikilink 双向链接
- Callout 标注语法
- 标签体系
- 文件命名和目录结构

### Step 2: 编写文档
按功能范围编写文档，遵循规范。

### Step 3: 用户审核 ⏸️
**必须等待用户审核。** 用户告知"通过"则完成；有遗漏则用户告知修正内容，回到 Step 2。

## 出口
功能文档审核通过。
